# CHANGELOG

## 1.0.0 — Republic Mod manager V 1.0 RUS

Base: Republic Mod Loader 1.0.1 (commit `57e567e5cccaa3c38aee7e9d599d2443d2460b10`), GPL-3.0.

New:

- Полный русский интерфейс и переключение языка (Авто/Русский/English) в настройках.
- Страница «Каталог Steam»: поиск, мультифильтр по категориям (AND), период, сортировки
  `trend` / `mostrecent` / `toprated`, пагинация, карточки с деталями от public
  `ISteamRemoteStorage/GetPublishedFileDetails`.
- Подписка/отписка прямо из каталога; Steam качает файлы; состояние игры не
  переопределяется.
- Машинный перевод описаний модов на русский: бесплатный Google-endpoint, локальный кэш по
  хешу текста, пауза при 429, bảoет защита URL/BBCode при переводе.
- Одноразовое уведомление о машинном переводе при первом открытии каталога.
- Окно настроек: язык, автоперевод, очистка кэша переводов/каталога.
- Переименование: `RepublicModManagerRUS.exe`, иконка и логотип форка, README/NOTICE;
  внутренние пути (`rml_runtime.dll`, `rml/`, knowledge root) сохранены рядом с upstream,
  чтобы существующая установка обновилась на месте.

Infrastructure:

- Каталог и переводы кэшируются в LocalAppData (`catalog/v1`, `translations/v1`);
  превью — кэш 30 дней, LRU 200 МБ.
- `go test ./...` покрывает ядра локализации, перевода, каталога и конфига.
