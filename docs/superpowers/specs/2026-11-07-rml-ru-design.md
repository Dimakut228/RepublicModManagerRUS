# RML-RU — дизайн улучшенной версии Republic Mod Loader

Дата: 2026-11-07
База: https://github.com/Ultimate-Universe/WRSR-RepublicModLoader, коммит `57e567e5cccaa3c38aee7e9d599d2443d2460b10`, версия 1.0.1
Лицензия базы: GPL-3.0

## 1. Контекст и зачем

Republic Mod Loader (RML) — лаунчер и менеджер модов для Workers & Resources: Soviet Republic. Состоит из двух бинарников:

- `RepublicModLoader.exe` — лаунчер на Go, собственный Win32/GDI-интерфейс, без сторонних Go-модулей.
- `rml_runtime.dll` — рантайм на C++, внедряется в игру, грузит DLL-плагины.

Сейчас интерфейс полностью английский, все строки зашиты литералами. Каталог мастерской ограничен уже установленными модами: поиск и сортировка по имени/ID/включённости есть, удалённого каталога, категорий, периода и перевода описаний нет.

Пользователь хочет:

- русский интерфейс;
- каталог Steam Workshop внутри программы с фильтрами, чтобы не листать страницы Steam;
- автоматический перевод описаний модов на русский;
- подписку/отписку из программы; скачивание и обновление файлов остаются за Steam;
- выпустить свою улучшенную версию.

## 2. Цели

1. Полный русский интерфейс лаунчера и полноценный английский, с переключением языка в настройках и сохранением выбора.
2. Каталог Steam Workshop: поиск, категории, период, сортировки, пагинация, карточка мода.
3. Подписка и отписка из каталога и из установленного списка. Файлы качает Steam.
4. Перевод описаний модов на русский: автоматически при открытии карточки, с кэшем и возможностью выключить.
5. Собственный GPL-3.0 релиз: исходники, тег, ZIP, README/NOTICE с атрибуцией.
6. Не сломать существующее: запуск игры, инъекцию рантайма, плейлисты, диагностику, Tesmio-совместимость.

## 3. Не-цели

- Скачивание, установка и обновление файлов модов без Steam.
- Перевод текста самой игры, модов внутри игры и названий модов.
- Редактирование или переупаковка содержимого модов.
- Собственный сервер каталога, аккаунты, рейтинги, комментарии.
- Автообновление лаунчера в v1.
- Публикация в Steam Workshop в v1.
- Перевод логов, отчётов и диагностических строк: они остаются английскими для поддержки.
- Локализация суффикса `Republic Mod Loader ... ACTIVE` в главном меню игры: это диагностический тег, трогать формат плана ради него в v1 не будем.

## 4. Анти-цели

Считаем провалом, даже если технически работает:

- сетевые запросы без уведомления и без возможности отключить;
- отправка на перевод чего-либо, кроме текста описания;
- публикация машинных переводов от имени авторов модов;
- использование бренда, иконки и названия upstream так, будто автор одобрил форк;
- нарушение GPL-3.0: закрытые изменения, отсутствие исходников, снятые уведомления;
- поломка запуска игры или существующих плейлистов.

## 5. Ограничения

- GPL-3.0: форк и продажа/раздача разрешены, но исходники обязаны быть доступны, лицензия и копирайты сохраняются, изменения описываются.
- Steam качает контент только по подписке. Лаунчер не может «установить» мод в обход Steam.
- Каталог Steam отдаётся HTML-страницами; API деталей публичный, без ключа. HTML может измениться.
- Официального рейтинга «звёзды» в публичном API деталей нет. Сортировка возможна по подпискам, просмотрам, дате; рейтинг — только парсингом страницы, в v1 не делаем.
- У модов нет метаданных языка. Фильтра «только русские моды» не будет.
- Бесплатный публичный переводчик — неофициальный endpoint без SLA. Нужен запасной вариант и честное сообщение об ошибке.
- Сборка: на текущей машине нет Go и CMake, есть Visual Studio 2022 и Python 3.12. Игра установлена: `E:\SteamLibrary\steamapps\common\SovietRepublic\SOVIET64.exe`; установлено 40 элементов Workshop.
- Интерфейс рисуется вручную; русские строки длиннее английских, нужны переносы/эллипсисы и проверка на 100–150% DPI.
- Шрифты `Segoe UI Variable`/`Segoe UI` поддерживают кириллицу; отдельный шрифт не нужен.

## 6. Рассмотренные подходы

1. **Минимальный форк.** Только русский интерфейс и фильтры по установленным модам. Дешево, но не решает задачу.
2. **Лаунчер-магазин (выбран).** Удалённый каталог, фильтры, подписка, перевод по кнопке/автоматически, встроенные локали. Умеренная сложность, всё в рамках существующей архитектуры.
3. **Максимум.** Ключ Steam Web API, локальная БД всех 13 386 модов, фоновый индекс, общий пакет переводов, автообновление. Дороже в разработке и сопровождении, требует ключ от пользователя.

Выбран вариант 2. Причины: покрывает все заявленные функции, не требует ключей и внешних сервисов для базовой работы, укладывается в текущие Go-зависимости (только stdlib), оставляет путь к варианту 3 без переделки UI.

## 7. Архитектура

Новые пакеты внутри `Source/launcher` (плоский `package main`, как в upstream):

- `locale_windows.go` — загрузка встроенных локалей, `tr(key)`, выбор языка, форматирование.
- `catalog_windows.go` — клиент каталога: browse-страницы, разбор, пагинация, фильтры, состояние.
- `catalog_details_windows.go` — пакетный `GetPublishedFileDetails`, нормализация, кэш.
- `translate_windows.go` — провайдеры перевода, защита разметки, кэш, очередь.
- `catalog_ui_windows.go` — отрисовка каталога и карточки, фильтры, кнопки подписки, интеграция с существующим canvas.
- `settings_ui_windows.go` — модальное окно настроек (язык, перевод, кэш).

Существующие файлы меняются точечно: `AppConfig` + `defaultConfig` (`model.go`), навигация/состояние (`app_windows.go`), сообщения Win32 (`main_windows.go`), общий список (`mod_list_windows.go`), `ui_pages_windows.go` (замена литералов и вкладка каталога).

Потоки: сеть только в goroutine, результат кладётся в поле `application` под мьютексом, UI перерисовывается через существующий механизм `PostMessage`/таймер. Отмена — по смене вкладки/выбору другого мода (флаг generation в запросе).

## 8. Локализация

### Формат

`Source/launcher/locales/en.json`, `ru.json`, встраиваются через `//go:embed locales/*.json`.

```json
{
  "meta": { "code": "ru", "name": "Русский", "version": 1 },
  "strings": {
    "nav.dashboard": "Главная",
    "nav.mods": "Моды",
    "common.launch": "Запустить Workers & Resources"
  }
}
```

- Ключи плоские, стабильные, с префиксами по экрану.
- Значения — только текст; форматирование через `fmt.Sprintf(tr("key"), args...)`.
- Неизвестный ключ возвращает английское значение, затем сам ключ. Ошибка не роняет UI.
- Тест проверяет совпадение наборов ключей en/ru и одинаковое число и тип глаголов `%s/%d`.
- Никаких сторонних i18n-библиотек.

### Выбор языка

- Новое поле `language` в `AppConfig` (`auto`, `ru`, `en`), по умолчанию `auto`.
- `auto`: язык Windows через `GetUserDefaultUILanguage`; русский для `0x0419`, иначе английский.
- Переключатель в настройках; применяется сразу без перезапуска.
- Русский — полноценный, английский остаётся полным (не «перевод ради галочки»).

### Объём

Пользовательские строки лаунчера: примерно 400–500 (по грубому подсчёту 450+ в `launcher/*.go`, из них часть — логи и внутренние ошибки). Переводим всё, что видит пользователь: навигация, карточки, кнопки, статусы, модальные окна, плейлисты, предупреждения, ошибки запуска, экраны плагинов/мастерской/разработки/диагностики.

Не переводим: `log_*`, JSON-отчёты, имена символов, тексты, приходящие из плагинов и Steam.

### Вёрстка

- Кнопки и метрики получают минимальную ширину по измеренному тексту либоellipsis.
- Проверка переносов в карточках, модалках, таблицах при 100%, 125%, 150% DPI.
- Длинные русские подписи не должны наезжать на переключатели и иконки.

## 9. Каталог Steam Workshop

### Источник списка

`GET https://steamcommunity.com/workshop/browse/` c параметрами:

- `appid=784150`
- `p=<страница>`
- `numperpage=30`
- `section=readytouseitems`
- `browsesort=trend|mostrecent|toprated` — только эти три значения реально работают; `mostsubscribed` отдаёт trend, сортировки по просмотрам нет
- `days=7|30|90|180|365` — период действует только для `trend`; для `mostrecent` и `toprated` параметр игнорируется
- `searchtext=<запрос>`
- `requiredtags[]=<категория>` / `excludedtags[]=<категория>`
- показ несовместимых — проверить фактическое имя параметра; если его нет, фильтровать на клиенте по признаку со страницы

Разбор: терпимый экстрактор по HTML (regexp по блокам `workshopItem`, ссылкам `filedetails/?id=<digits>` и заголовкам). Без сторонних HTML-парсеров. Если распознано 0 элементов — показать понятную ошибку и кнопку «Повторить», а не пустой список.

Категории для фильтра берутся из самой страницы browse (Text modification, Vehicle skin, Landscape, Vehicle, Building, World Maps, Required DLC, Biomes, Early Start, Soundtrack и подкатегории). Список кэшируется и обновляется вместе с каталогом.

### Детали

`POST https://api.steampowered.com/ISteamRemoteStorage/GetPublishedFileDetails/v1/`
Тело: `itemcount=N`, `publishedfileids[0..N-1]=<id>`, до 100 за запрос. Без ключа.

Нормализуем: `title`, `description`, `time_created`, `time_updated`, `subscriptions`, `favorited`, `views`, `preview_url`, `file_size`, `creator`, `visibility`, `banned`, `tags`.

### Состояние

- «Установлен» = существует папка `steamapps/workshop/content/784150/<id>`.
- «Подписан» = бит `k_ERemoteUserItemStateSubscribed` через `steam_api64.dll` (уже реализовано в `steam_workshop_windows.go`).
- Кнопка в карточке: «Подписаться» / «Отписаться» / «Установлен».
- После подписки показываем прогресс «Steam скачивает», обновляем состояние по таймеру; файлы не трогаем.
- Отписка переиспользует существующий сценарий с подтверждением и удалением файлов (уже есть).

### Сортировки и фильтры v1

- Поиск по названию (через `searchtext`, с серверной стороны).
- Категории: мультивыбор с семантикой Steam — выбранные теги объединяются через AND. Подпись у фильтра: «Все выбранные категории». Результат совпадает с фильтрами на сайте Steam.
- Период: неделя/месяц/3 месяца/полгода/год/всё время. Активен только для сортировки «Популярные»; для остальных скрыт или неактивен с пояснением.
- Сортировка: «Популярные за период» (`trend`), «Новые» (`mostrecent`), «Лучшие» (`toprated`). Сортировок по подпискам и просмотрам не обещаем, потому что Steam их не отдаёт.
- Чекбокс «показывать несовместимые» (по умолчанию выкл).
- Фильтр «только установленные» переключает на существующий локальный список.
- Сброс фильтров.

### Кэш

- Страницы каталога и детали: `%LOCALAPPDATA%/<RML knowledge root>/catalog/v1/`.
- TTL: список 6 часов, детали 24 часа, превью 30 дней.
- Превью скачиваются в `thumbs/`, максимум 512 КБ на файл, общий лимит 200 МБ с LRU-чисткой.
- Офлайн: показываем последний кэш и баннер «Нет сети, показаны сохранённые данные».

## 10. Перевод описаний

### Провайдер

Один провайдер, без выбора и без ключей: `GET https://translate.googleapis.com/translate_a/single?client=gtx&sl=auto&tl=ru&dt=t&q=...`

- Перевод всегда на русский. При английском интерфейсе автоперевод отключён, показывается оригинал.
- Неофициальный endpoint: может троттлить или измениться. Ошибка не блокирует UI, показываем оригинал и понятное сообщение.
- Настройки провайдера и поля для API-ключа в интерфейсе и конфиге отсутствуют.

### Поведение

- Перевод выполняется при открытии карточки мода, если включена настройка «Переводить описания автоматически» (по умолчанию вкл). Работает и для карточки каталога, и для карточки уже установленного мода: один кэш по хешу текста, чтобы один мод не показывался на русском в каталоге и на английском во вкладке «Установленные».
- При первом открытии каталога показывается одноразовое ненавязчивое уведомление: «Описания переводятся через Google; отключить можно в настройках». Оно не блокирует работу и запоминается в конфиге.
- В карточке два блока: «Оригинал» и «Перевод» (перевод сверху, оригинал сворачиваемый). Кнопки «Перевести заново», «Показать оригинал».
- Названия модов не переводим.
- Если текст уже преимущественно русский (доля кириллицы > 40%), перевод не запрашивается.
- Список не переводится: только выбранная карточка. Это экономит трафик и лимиты.

### Сохранение разметки

- Маскируем URL, BBCode-теги, `{placeholder}`, `%s`, длинные числа: `⟦0⟧`, `⟦1⟧`…
- Режем по абзацам/предложениям до 4000 символов на запрос (лимит endpoint), склеиваем обратно.
- После перевода восстанавливаем токены; если токен потерян — показываем оригинал и ошибку, не портим текст.
- Управляющие символы вырезаем, длину ответа ограничиваем.

### Кэш

- Ключ: `targetLang + modID + sha256(нормализованный исходник) + версия формата`.
- Файл: `%LOCALAPPDATA%/<knowledge root>/translations/v1/<lang>/<modID>-<hash>.json`.
- Перевод живёт, пока не изменился исходный текст.
- Кнопка «Очистить кэш переводов» в настройках.
- Общий пакет переводов не публикуем: описания — чужой текст.

### Очередь и лимиты

- Один запрос перевода одновременно, пауза 300 мс.
- Таймаут 10 с, 1 повтор при 5xx/таймауте.
- При 429/403 — не повторять 10 минут, показать сообщение.
- При смене карточки запрос отменяется (generation).

## 11. Интерфейс

Вкладка «Мастерская» получает переключатель:

`Установленные | Каталог Steam`

Каталог:

- слева список: превью, название, автор, подписки/просмотры, размер, бейдж «Установлен»;
- сверху строка поиска, кнопка фильтров, сортировка, счётчик результатов;
- справа карточка: большое превью, название, автор, дата, размер, кнопка подписки, описание с переводом;
- пагинация «Назад/Вперёд» и номер страницы;
- состояние загрузки/ошибки/офлайна.

Настройки:

- язык интерфейса: Авто / Русский / English;
- переводить описания автоматически;
- очистить кэш переводов;
- очистить кэш каталога.

Существующие экраны и поведение не меняются, кроме русских подписей.

## 12. Данные и конфиг

Новые поля `AppConfig` (с `omitempty`, старые конфиги читаются без миграции):

```go
Language                 string `json:"language,omitempty"`                 // auto|ru|en
AutoTranslate            bool   `json:"autoTranslateDescriptions,omitempty"`
TranslationNoticeShown   bool   `json:"translationNoticeShown,omitempty"`
CatalogSort              string `json:"catalogSort,omitempty"`
CatalogPeriod            string `json:"catalogPeriod,omitempty"`
CatalogShowIncompatible  bool   `json:"catalogShowIncompatible,omitempty"`
```

`defaultConfig`: `Language="auto"`, `AutoTranslate=true`, `TranslationNoticeShown=false`.

Каталог, переводы и превью — в knowledge root в LocalAppData, не в папке Workshop (она может быть перезаписана Steam).

## 13. Сеть и сбои

- Свой User-Agent: `<AppName>/<version>`.
- Таймауты 10 с, ограничение размера ответа.
- Ретраи только для 5xx/таймаута, максимум 2, с задержкой.
- 429 — пауза и сообщение, без долбёжки.
- Все сетевые операции выключены, если нет интернета; UI не зависает.
- Никаких фоновых запросов без действия пользователя, кроме обновления открытого каталога.

## 14. Безопасность

- ID модов проверяются как цифры, ограничение длины.
- HTML Steam не рендерится; текст очищается от управляющих символов и ограничивается по длине.
- Ссылки не открываются автоматически.
- Переводятся только описания; имя пользователя, путь и настройки не отправляются.
- Фиксированные хосты, только HTTPS, без редиректов на другие домены.
- Никакого исполнения кода из каталога.

## 15. Совместимость и миграция

- Формат `config.json` расширяется, старые поля не меняются; обратная совместимость с upstream-конфигом.
- Плейлисты и их экспорт/импорт не меняются.
- Запуск игры, инъекция, Tesmio-совместимость не затрагиваются.
- Если каталог/перевод падают, лаунчер работает как раньше.
- Откат: удалить новые поля/файлы кэша, поведение возвращается к upstream.

## 17. Тестирование

Автотесты (`go test ./...`):

- паритет ключей en/ru и глаголов форматирования;
- fallback неизвестного ключа;
- маскирование/восстановление URL и BBCode;
- ключ кэша перевода меняется при изменении текста;
- разбор сохранённой HTML-фикстуры browse (сеть не используется);
- разбор JSON деталей и устойчивость к отсутствующим полям;
- миграция конфига: старый JSON → новые значения по умолчанию.

## 19. Риски

| Риск | Вероятность | Влияние | Меры |
|---|---|---|---|
| Steam меняет HTML browse | средняя | каталог ломается | фикстуры, понятная ошибка, быстрый фикс |
| Неофициальный переводчик блокирует | средняя | перевод не работает | кэш, понятное сообщение, отключение автоперевода |
| Лимиты Steam/429 | средняя | каталог тормозит | паузы, кэш, ретраи с backoff |
| Русский текст ломает вёрстку | высокая | UI нечитаем | измерение текста, ellipsis, проверка DPI |
| Случайно сломать запуск игры | низкая | критично | не трогаем инъекцию, регресс-тест запуска |
| Нарушение GPL/бренда | средняя | юридические проблемы | NOTICE, исходники, пометка «Unofficial», своя иконка |

## 20. Решения, оставленные за мной

- Перевод — только бесплатный Google-endpoint, без выбора провайдера и без ключей.
- Названия модов не переводим, только описания; переводим и каталог, и установленные моды.
- При английском интерфейсе автоперевод отключён, показывается оригинал.
- Логи и отчёты остаются английскими.
- Кэш — в LocalAppData, не в папке Workshop.
- Рейтинг «звёзды» не фильтруем; сортировки только `trend`, `mostrecent`, `toprated`, период только для `trend`.
- Мультивыбор категорий — AND, как на сайте Steam.
- При первом открытии каталога — одноразовое уведомление о сетевом переводе, без блокирующего согласия.
- Суффикс RML в главном меню игры остаётся английским.
- Внутренние имена (`rml_runtime.dll`, `rml/`, путь knowledge, класс окна, формат конфига) не меняем, чтобы существующая установка обновлялась на месте и не теряла настройки, плейлисты и symbol cache. Меняются имя EXE, отображаемое имя, иконка и заголовок окна.
- Первый релиз — portable ZIP на GitHub, без установщика и автообновления; Steam Workshop — позже.
